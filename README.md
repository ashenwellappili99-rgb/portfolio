# Ashen Wellappili - Personal Portfolio 🚀

A modern, responsive personal portfolio web application built with **React** and **Vite**, featuring technical skills, verified certifications, real software projects, and an interactive academic journey.

![Portfolio Preview](public/portfolio.jpg)

## 📌 Features

- ⚛️ **React & Vite**: Fast build times and smooth component rendering.
- 🎨 **Theme Mode**: Dynamic Light/Dark mode toggling with React Context.
- 📜 **Certifications & Badges**: Embedded Microsoft **AI Skills Fest 2026** badge with direct Credly verification link.
- 💻 **Project Showcase**: Real projects including Coffee Shop Web App, QuickFix Repair System (C/C++ OOP), and React Portfolio.
- 🎓 **Academic Journey**: Timeline detailing skills and practical knowledge gained at ICBT Campus.
- 📱 **Fully Responsive**: Optimized for desktop, tablet, and mobile views.

---

## 🛠️ Tech Stack

- **Frontend Framework**: React 18
- **Build Tool**: Vite
- **Styling**: Vanilla CSS3 (Custom Variables, Flexbox/Grid, Animations)
- **Icons**: FontAwesome (`@fortawesome/react-fontawesome`) & Lucide React (`lucide-react`)

## 🚀 Getting Started

### Prerequisites

Ensure you have [Node.js](https://nodejs.org/) installed (v16+ recommended).

### Installation & Local Setup

1. **Clone the Repository**:
   ```bash
   git clone https://github.com/ashenwellappili99-rgb/portfolio.git
   cd portfolio
   ```

2. **Install Dependencies**:
   ```bash
   npm install
   ```

3. **Start Development Server**:
   ```bash
   npm run dev
   ```
   Open `http://localhost:5173/` in your browser.

4. **Build for Production**:
   ```bash
   npm run build
   ```
